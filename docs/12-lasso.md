# 悬浮球圈选需求

> 修订日期：2026-10-31。本文只记录已经约定的交互效果，不涉及实现方式。
>
> 圈选和划词是两条独立入口：划词处理文字，圈选处理屏幕区域。两者共用悬浮球的对话面板和「发给 Agent」的落点，但互不替代。

用户拖动悬浮球旁边的小卫星球，在屏幕上画一个圈。松手后出现一个可调整的矩形框；点「发送给 Agent」，这张截图就变成悬浮球这一轮对话的首帧屏幕，用户可以直接说话或打字提问。

## 1. 触发

- 悬浮球旁边常驻一颗小卫星球，约 24px，半透明灰底、白色描边，贴在主球右下缘，和 CoView 的小圈选球位置一致。
- 按住小卫星球拖动即开始圈选；拖动超过 4px 才生效，避免误触。
- 拖动时主球不动，屏幕上只出现蓝色轨迹，不压暗背景，屏幕内容保持实时可见。
- 轨迹为蓝色 3px 圆头线，每移动 2px 记录一个点。
- 圈选只支持当前显示器；跨屏拖动时按起点所在屏处理，不跨屏取图。
- 以下情况不允许圈选，小卫星球显示为禁用态：
  - Agent 正在执行任务或正在操作屏幕。
  - 圈选总开关关闭。
  - 当前没有可用的 helper 连接。
- 圈选期间暂停划词工具条，避免拖动被误判成选字。

## 2. 松手与确认框

松手后从轨迹中找最大的自交闭环，取外接矩形：

- 找到闭环：进入确认框。
- 没找到闭环：轨迹渐隐，球旁提示「没有闭合，再画一圈」，不产生截图、不进入确认框。

确认框是一层覆盖当前显示器的全屏层：

- 矩形框内部保持真实屏幕亮度，框外压暗；压暗只影响显示，不影响最终图片。
- 矩形框可整体拖动平移；四角可拉伸改变大小；有最小边长，不能缩到不可用。
- 框上提供三个按钮：**发送给 Agent**、**翻译**、**复制**。
- 按钮靠近屏幕边缘时自动翻到框内侧，不能被裁到屏幕外。
- 按 Esc 取消；点矩形框外取消；取消后不产生任何截图。
- 调整框的过程中不反复截图；只有点按钮的瞬间才按最终框截图。

## 3. 发给 Agent

点「发送给 Agent」：

- 确认框消失，悬浮球面板自动展开并固定在屏幕上，不因鼠标移开而收起。
- 输入框上方出现一张小缩略图 chip，位置和划词「发给 Agent」的文字 chip 一致，但内容是图片。
- 用户必须给一句指令才能发送：可以语音输入，也可以在输入框里打字；空内容不能发送。
- 发送后 chip 消失，这条指令和它的截图进入正常对话。
- 再圈一次会替换当前 chip；切换历史对话或新建对话时清空当前 chip。

### 3.1 图片内容

- 缩略图和最终发给 Agent 的图是同一张：**前台应用窗口的截图**，和悬浮球 Agent 平时首帧截图的目标一致。
- 矩形框内部亮，窗口内框外暗；窗口外不进入图片。
- 如果矩形框超出前台窗口，截图范围扩展到「前台窗口 ∪ 矩形框」，保证框内内容完整；框外仍在图内压暗。
- 单屏；选区超出显示器时裁到当前显示器。
- 截图不烤入鼠标光标。
- 图片里不出现确认框的边框、手柄、按钮、轨迹层、球和面板；框外压暗是最终图片的一部分，必须保留。
- 图片作为持久附件保存，重启后仍可回看。

### 3.2 首帧替换

- 这一轮 Agent 的首帧屏幕观察就是这张高亮图，不再额外截一张当前屏幕。
- 首帧观察仍然带正常的前台应用信息、屏幕坐标和尺寸，GUI 工具的坐标链路与普通任务一致。
- 这一轮不禁止 GUI 工具，也不套用划词的「只回答、不操作」限制。
- 之后的每个工具动作照样截新图、走原来的观察链路。
- 模型只收到这一份图，不因为对话历史要显示缩略图而重复发送。
- 这个替换只作用于圈选发送的这一轮；后续用户再发消息，首帧行为恢复正常。

## 4. 翻译

点「翻译」：

- 确认框关闭，只截矩形框内的裁切图。
- 悬浮球面板展开并固定，在球内显示「截图翻译」结果卡。
- 翻译结果和划词翻译一样，带「未计入对话」标记；不进入对话历史、不进入模型上下文。
- 目标语言跟随现有划词翻译的语言设置。
- 翻译失败时在球内提示失败原因；不留下半截结果。
- 翻译使用框内裁切图，不是整窗高亮图。

## 5. 复制

点「复制」：

- 只截矩形框内的裁切图，写入系统剪贴板。
- 确认框不关闭，用户可以继续调整框或再点复制。
- 复制成功后按钮短暂显示完成态（打勾）。
- 复制失败时在框旁提示，不关闭确认框。

## 6. 对话历史

- 发送后，用户气泡里、指令文字上方显示这张截图的小缩略图。
- 缩略图内容与发送时 chip 一致，是整窗高亮图，不是裁切图。
- 点击缩略图打开居中大图预览；预览显示整窗高亮图，Esc 或点背景关闭。
- 缩略图来自持久附件，重启应用、打开旧对话都能恢复。
- 历史重放按同一规则生成缩略图，不需要当年额外保存一份 UI 数据。
- 图片不在对话气泡里以原始大图渲染，只做小缩略图和点开预览。

## 7. 边界与门禁

| 场景 | 行为 |
| --- | --- |
| 没有闭环 | 轨迹渐隐 + 轻提示，不截图 |
| Esc / 点框外 | 取消确认框，不截图 |
| 圈选期间切换应用 | 允许；确认框保持在原显示器 |
| Agent 正在执行 | 小卫星球禁用，不能开始圈选 |
| 屏幕录制权限缺失 | 点发送/翻译/复制时复用现有权限引导，不产生半成品 |
| 截图失败 | 保留确认框，提示失败，可重试或取消 |
| 切换/新建对话 | 清空未发送的 chip 和待用首帧 |
| 连续圈选 | 新的替换旧的，不堆叠 |
| 多显示器 | 只处理起点所在显示器；不做跨屏拼接 |
| 窗口全屏 / 全屏 Space | 确认框和轨迹仍显示在当前显示器最上层 |

## 8. 平台

- macOS 与 Windows 都提供完整圈选功能。
- Windows 需要正确处理 DPI 缩放：确认框和轨迹使用逻辑坐标，截图与高亮合成使用物理像素。
- 权限归属与现有 Computer Use 一致，不新增独立的权限主体。

## 9. 不在本期范围

- 选区 OCR 或本地文字识别。
- 保存 PNG 到磁盘、下载按钮。
- 「Agent 讲解」独立动作。
- 全局快捷键圈选、矩形直选入口。
- 跨显示器拼接截图。
- 固定选区、连续截图、定时刷新。
- 多边形蒙版导出。

## 10. 验收点

1. 小卫星球常驻，拖动可画出蓝色轨迹；不足 4px 不触发。
2. 闭环松手后出现可平移、可四角拉伸的确认框；无闭环不截图。
3. 确认框外压暗、框内实时亮；Esc 和点框外都能取消。
4. 「发送给 Agent」后球展开固定，输入框上方出现整窗高亮缩略图。
5. 必须给一句指令才能发送；空内容不能发。
6. 发送后这一轮首帧就是圈选高亮图，且没有额外截当前屏幕。
7. 首帧仍带前台窗口信息与坐标，GUI 工具可以正常使用。
8. 翻译用框内裁切图，结果显示在球内并标记「未计入对话」。
9. 复制用框内裁切图，确认框不关闭，按钮出现完成态。
10. 历史气泡显示整窗高亮缩略图，点开可看大图，重启后仍在。
11. Agent 执行期间小卫星球禁用；圈选期间划词工具条不出现。
12. macOS 与 Windows 行为一致，Windows 高 DPI 下选区不偏移。
