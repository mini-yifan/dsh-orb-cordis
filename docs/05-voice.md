# 悬浮球语音需求

> 修订日期：2026-10-17。本文只记录已经约定的交互。实现材料见文末。

语音挂在现有悬浮球上，不另做一套对话。唤醒、语音输入、TTS 共用同一路麦克风。唤醒和语音输入互相切换；Agent 在干活、提问卡在等答案，或 TTS 还在说时，两路都关掉。TTS 只念显示框当前这场对话里、Agent 写给用户的正文，以及提问卡弹出时的一句提示语。播报不挡住 Agent 继续执行。

## 1. 三种听法

听法由两件事决定：显示框是否**固定**，Agent 是否**空闲**。鼠标悬停把面板临时展开，不算固定。

| 状态 | 唤醒 | 语音输入 | TTS |
|---|---|---|---|
| 没固定，Agent 空闲 | 开 | 关 | 无正文则不播 |
| 已固定，Agent 空闲 | 关 | 开 | 无正文则不播 |
| Agent 正在工作、提问卡在等答案，或收尾正文还在播 | 关 | 关 | 只播当前这场的正文和提问提示语 |

从唤醒切到语音输入时麦克风不断开，固定之后立刻说的那句开头要留给语音输入。某一项在设置里关掉后，上表里对应的那一列不再发生，其余照旧。

Agent 一开始干活，现有逻辑会把显示框展开并固定。执行期间仍按上表第三行：只播报，不听。后台任务把面板弹出来时同样处理。执行结束并且播报也结束后，再看固定还在不在：还固定着就听语音输入，已经取消固定就只听唤醒。

干活途中单击球，固定会取消，显示框因为任务还在先不收。这时麦克风保持全关。任务和播报都结束后，按当时的固定状态恢复。

## 2. 唤醒

没固定时才听唤醒词。唤醒命中只做一件事：把显示框展开并固定。效果与单击悬浮球把它钉住相同。

唤醒不发送消息，不把这句话交给 Agent。已经固定时不再听唤醒，再喊也没有反应。

唤醒成功后，本地说一句回复语，出厂是「我在」。这句话只出声，不进对话，不发给 Agent。回复语在设置里可改。留空，或 TTS 开关关掉时，不说这句，显示框照样固定。这句还在播的时候，不把麦克风里的声音当成用户指令，播完再开始听。

取消固定的方式：单击球；说出退下口令；空闲超时。这三样都只取消固定，不主动把显示框收成只剩一个球。收不收显示框沿用现在的规则：当时鼠标不在悬浮球窗口上（球或显示框），就收回；鼠标还在上面，显示框留着，等鼠标离开再收回。Agent 空闲时把球拖走仍按现在的拖动：取消固定并收回显示框。

已固定、Agent 空闲、没有提问卡在等、收尾和提问提示语都已播完时，开始算空闲。出厂 30 秒没有新的交互，就取消固定，然后回到只听唤醒。鼠标停在球上或显示框上也不打断这 30 秒。下面这些重新计时，或在进行中把表停住：

- 输入框里有按键，或发出一条文字指令
- 一段语音还没说完；说完并作为指令送出后，再重新计时
- Agent 正在干活、提问卡还在等点选、收尾正文或提问提示语还在播

取消固定时不说退下回复语，也不发消息。输入框里没发出去的字保留。时长在设置里可改，见第 7.4 节。

## 3. 语音输入

已固定且 Agent 空闲时，语音输入开着。没有单独的语音按钮。

用户说完一段（话音落下、静音判定结束），整段转成文字，作为一条用户消息出现在显示框里，并走现在打字后发送的同一条路径交给悬浮球 Agent。固定没有取消之前，下一句可以直接说，不必再唤醒。

说的过程中不出逐字稿，说完出整段。

### 3.1 退下

语音输入开着时，额外认一组固定整句。口令和退下后的回复语都在设置里改。出厂口令是「你退下吧」和「退下吧」，可以再加多条。出厂回复是「好的，再见」。

用户说的整句命中其中任意一条时：

- 这句话不进输入框，不上屏，不发给 Agent
- 立刻取消固定，回到只听唤醒。不主动收回显示框；鼠标不在悬浮球窗口上才按现有规则收回，鼠标还在上面就留着
- 本地说设置里的退下回复语

这句回复只出声，不进对话，也不是 Agent 的回复。回复语留空，或 TTS 开关关掉时，不说这句，照样只取消固定。

口令只匹配整句，夹在别的话里不触发。一条都不填时，没有退下口令。Agent 正在干活、提问卡在等答案，或收尾还在播时麦克风是关的，这时说退下听不到。

## 4. TTS 播什么

TTS 不看这句话是说进去的还是打进去的。显示框当前这场对话里，Agent 写给用户看的正文出现，就按下面的规则考虑播报。

正文是这场对话里和思考、工具卡分开的那种文字：模型输出里的 `text`。一场任务里可以有多句，包括干活途中那句短的意图，以及收尾那几句结果。

只播显示框正在显示的这场。历史里的其他对话、主窗口里的其他会话，悬浮球 Agent 即使写出正文，也不播。同一场对话的正文，只要显示框当前就是这场，就按本文播报。

显示框换到另一场时，上一场正在播的声音停下，队列清空。之后只处理新这场的正文和提问提示语。

提问卡弹出时，不念题目、短标签、补充内容、选项，不论有几问。只播设置里的一句提问提示语，出厂是「我有几个问题，你来选一下」。一问和多问都是这一句，不按问题条数重复。这句和收尾正文一样必须播：喇叭空着就立刻播，正在播别的就进队列，不丢。它只出声，不进对话，也不发给 Agent。提问卡还在等答案的整段时间，麦克风保持关闭。用户只能在卡片上点选，第一版不用语音回答。用户点选或取消后，这句还没播完也立刻停。提示语留空，或 TTS 开关关掉时，不说这句，卡片照样出现，麦克风照样关闭。Agent 若另外用正文把问题写了一遍，那句正文仍按正文处理。

这些不播：

- 思考（`reasoning` / `thinking`）
- 工具调用、参数、结果
- 面板上的状态，例如「深度求索中」
- 提问卡上的题目、短标签、补充内容、选项

## 5. TTS 与执行并行

TTS 不得拖慢 Agent。工具调用和后续生成继续进行，不等当前这句话播完。

喇叭空着时，新来的正文直接播。途中一句、提问提示语和收尾一段都这样。

喇叭正在播、又来了新的正文时：

- **收尾正文**：当前任务已经结束，Agent 最后说给用户的那段。放进队列。正在播的这句播完，立刻播它。队列里同时只留这一段收尾。收尾若是连续几句，接在一起，算同一段。
- **提问提示语**：提问卡弹出时的那一句固定话。和收尾一样必须播，放进队列。正在播的这句播完就播它。它不占收尾那个名额，也不被后来的收尾挤掉。一张卡只播一句，不按问题条数加长。
- **途中正文**：任务还要继续，只是中间说的一句。直接丢掉，不进队列，之后也不补播。

因此途中那几句能赶上喇叭就播，赶不上就让给提问或最后的结果。提问和结果最晚会在当前这句结束后马上听到。

收尾还在播，或提问卡还在等答案时，唤醒和语音输入保持关闭。收尾播完、并且没有提问卡在等，再按第 1 节恢复。

## 6. 停止按钮

显示框上现有的「停止」按钮，同时管 Agent 执行和 TTS。

按钮在这两段时间里都留着：

- Agent 正在执行
- 执行已经结束，但 TTS 还在播，或队列里还有收尾

两段都结束后按钮才消失。收尾还在播时，显示框保持展开，按钮留在上面。播完或被停止之后，若固定已经被取消，显示框再按现有规则收回。

点击「停止」时一起做：

- Agent 还在执行，就立刻停掉这场执行
- 正在播的 TTS 立刻停，播到一半也停
- 清空 TTS 队列，排着的收尾和提问提示语也不再播

执行途中点击，三件一起做。只剩收尾在播时点击，停播报并清空队列。两边都停了，按钮消失，再按第 1 节恢复麦克风。

## 7. 悬浮球设置里的语音

主窗口「设置 → 悬浮球」里增加一组「语音」。球上「打开悬浮球设置」也进这一页。三项出厂都开启，可以单独关掉。

### 7.1 语音唤醒

- **开关。** 关掉后，没固定时也不听唤醒词。要固定显示框，仍用单击球。
- **唤醒参数。** 灵敏度、增强分、判定粒度、连触发冷却。出厂值用唤醒文档的默认定值：灵敏度 0.25、增强分 1、判定粒度 160ms、冷却 1.5 秒。
- **唤醒词。** 可改。出厂放一套中文唤醒词，设置里显示当前词；具体出厂词在实现时确定。
- **唤醒后的回复语。** 可改，出厂「我在」。行为见第 2 节。

### 7.2 语音输入

- **开关。** 关掉后，显示框即使固定着也不听指令，退下口令也不生效。
- **退下口令。** 可填多条。出厂两条：「你退下吧」「退下吧」。行为见第 3.1 节。
- **退下后的回复语。** 可改，出厂「好的，再见」。

### 7.3 TTS

- **开关。** 关掉后，不播 Agent 正文和提问提示语，也不播唤醒回复语和退下回复语。固定、收回、上屏、发送都照常。「停止」按钮只跟着 Agent 执行，不再为播报多留。
- **提问提示语。** 可改，出厂「我有几个问题，你来选一下」。提问卡弹出时只播这一句，不论有几问。行为见第 4 节。
- **TTS 参数。** 设置里至少提供语速。出厂 1.5 倍，最高 3.0 倍，与 TTS 文档的推荐档位一致。其余合成参数沿用该文档的出厂定值。

### 7.4 空闲后取消固定

- **空闲时长。** 可改，出厂 30 秒。已固定且没有新的文字或语音指令时，到时只取消固定。鼠标在不在上面不影响计时，也不决定要不要取消固定。显示框收不收仍看当时鼠标的位置。行为见第 2 节。

## 8. 一轮怎么走

1. 球没收起固定。用户喊唤醒词，显示框展开并固定，说「我在」，然后开始听指令。
2. 用户说「查一下今天的天气」。说完后整句上屏并发送。
3. Agent 开始干活。唤醒和语音输入都关掉。途中若说出「我去查一下今天的天气」，喇叭空着就播；若上一句还没播完，这句途中的话丢掉。
4. 思考和工具调用继续，不等播报。Agent 若弹出提问卡，只说「我有几个问题，你来选一下」，不念题目、内容和选项。这一句必须播，喇叭忙就排队。卡片还在时麦克风保持关闭，用户只能在卡片上选择。点选或取消后，这句还在播也停下。
5. 任务结束，收尾正文若赶上喇叭就立刻播；若喇叭还被上一句占着，就排队，上一句一完马上播。这段时间「停止」仍在。
6. 收尾播完，「停止」消失。显示框若还固定着，可以接着说下一句。30 秒没有新的指令，就只取消固定，回到只听唤醒；鼠标不在悬浮球窗口上时，显示框按现有规则收回。用户说「退下吧」，则不上屏、不发给 Agent，同样只取消固定，并说「好的，再见」。

用户在第 3 步到收尾播完之前点击「停止」：执行停、播报停、队列清空，按钮消失。

## 10. 本次不做

- 单独的语音按钮
- 用户用说话打断正在播的 TTS（要停播报，点「停止」）
- 把提问卡的题目、补充内容、选项念出来。提问只播设置里的那一句提示语
- 用语音回答提问卡。第一版只能在卡片上选择，提问期间麦克风关闭
- 把途中没赶上喇叭的正文补播
- 为语音输入再提供一套 VAD / ASR 参数（语音输入在设置里只有开关和退下相关项）
