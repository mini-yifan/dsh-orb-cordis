# 悬浮球语音播报需求

> 对齐日期：2026-10-22。本文只记录已经约定的交互。实现材料见文末。
>
> 与 [05-voice.md](05-voice.md)、[07-voice-listen.md](07-voice-listen.md) 冲突时，播报用本地还是千问、设置里怎么选、本地模型不在时哪些还能改，以本文为准。被本文改掉的是 05 第 7.3 节里「语速只有本地这一档」，以及第 7.5 节里「TTS 模型不在就锁住播报开关、提问提示语、语速，以及唤醒回复语、退下回复语」。07 第 10 节留的模型名单、密钥放哪、各项参数，由本文定。
>
> 播什么、什么时候丢、什么时候排队，仍按 05。听法、插话、退下、停止按钮，仍按 07。听和说不读当前播报用的是本地还是千问。

用户可以在设置里选择语音播报用本地模型，还是用千问。出厂用本地。选了千问并且填了阿里云百炼的 API Key，播报走千问云端。没选千问，走现在这一份本地模型。

要说的句子不变：当前这场对话里 Agent 写给用户的正文、提问提示语、唤醒回复语、退下回复语。这些都交给当前选中的那一种。

## 1. 本地与千问

| 播报 | 是什么 | 出厂 |
|---|---|---|
| 本地 | 现在这一份要下载的语音播报模型 | 是，升级后仍走本地 |
| 千问 | 阿里云百炼实时语音合成，模型 `qwen3-tts-flash-realtime` | 否 |

千问固定用华北 2（北京）。不提供地域切换，也不让用户改模型名。API Key 只认设置里手填的那一串，不从环境变量或本机 shell 配置里读。

## 2. 什么时候走哪一条

| 用户选的 | Key | 本地模型 | 实际播报 |
|---|---|---|---|
| 千问 | 已填，且这一次请求成功 | 有没有都行 | 千问 |
| 千问 | 空、无效、超时或断网 | 有没有都行 | 这一句不说 |
| 本地 | 不看 | 已下载 | 本地 |
| 本地 | 不看 | 没下载 | 不说，与现在相同 |

前后空白不算已填。选了千问就不改走本地，本地模型已经下好也一样。

没就绪和这一次失败，用户听到的都是没有这句声音，处理不一样：

- **没就绪。** 选了千问但 Key 是空的，或选了本地但文件没下齐。这一列不发生，效果与播报开关关掉相同。句子不交出去，也不算「正在播」。开关在设置里保持用户的选择。
- **这一次失败。** Key 无效、超时或断网。这一句交给千问，从交出去到失败回来算「正在播」，随后结束，喇叭无声。首包超时（3 秒没有音频）会换一条新连接重试，最多重试两次；只有这一次已经出过音频才不重试，避免整句重念；三次都失败才结束。不弹窗，不清掉 Key，也不改回本地。队列里下一句按 05 和 07 继续。

## 3. 设置

位置仍是主窗口「设置 → 悬浮球」的「语音」里，TTS 这一组。球上「打开悬浮球设置」也进这一页。

这一组增加一项，用来选择本地或千问。出厂为本地。换成另一种时，原来那种已保存的 Key、音色、语速都留着，换回去不用重填。

千问选中时，这一组另外显示：

- **API Key。** 用户自己粘贴。留空就是没填。
- **音色。** 见第 4 节。出厂芊悦。
- **语速。** 0.5–2.0，步进 0.1，出厂 1.4。1.0 是原速。

本地选中时，语速仍按 05：1–3，步进 0.1，出厂 1.5。两种语速分开存。选中哪一种，设置里就显示哪一种的语速。

两种播报共用一项「音量」。0–200%，步进 1%，出厂 100%。100% 是模型原始音量，200% 是最大放大；0% 静音，但不等于关掉播报开关。音量是播放端的增益，不改本地模型或千问的参数，也不改系统音量。换本地 / 千问、换音色、换语速、改音量，都从下一句起生效；已经交出去的那一句用开始时的设置。

「下载 TTS 语音播报模型」在选本地和选千问时都留着。初次下载、进度、已存在之后的更新，仍按 05 第 7.5 节。选了千问时，这个按钮不是打开播报的前提。

下面这些不因为本地模型不在而锁住，选本地或选千问都可以改：本地 / 千问这项选择、API Key、千问音色、千问语速。

选中千问时，下面这些也不再因为本地模型不在而锁住：播报开关、提问提示语、唤醒后的回复语、退下后的回复语、音量。本地文件没下，用户仍然可以打开播报。

选中本地、本地模型不在时，上述四项和音量仍按 05 第 7.5 节锁住，弹窗仍说明要下载 TTS 模型。本地 / 千问这项选择，以及千问那三项，保持可改。

提问提示语、唤醒回复语、退下回复语的出厂文案仍按 05。播报开关出厂仍是开。

Key 存在本机的语音配置里，和别的语音选项放在一起。不写入日志，不出现在报错文案里。

## 4. 千问的音色和语速

音色用百炼实时语音合成的 48 个系统音色。设置里分成两组，每项显示「中文名 · 性别 · 一句话特点」。保存和发送用下表的 voice 原文，区分大小写。名称中间的空格保留，例如 `Eldric Sage`、`Ono Anna`、`Radio Gol`。

方言也是选一个音色，没有单独的方言开关。语言固定为中文。句里的英文由同一个音色读，不拆成另一段，也不另设英文语速。

出厂音色是芊悦（Cherry）。换音色、换语速、或从本地换成千问、从千问换成本地，都从下一句起生效。已经交出去的那一句用开始时的设置，除非被停掉。

没有独立的音高。音量是本地和千问共用的一项播放增益，见第 3 节；它不改模型参数。

## 5. 一句怎么说、怎么停

队列仍按句把文字交给当前选中的那一种。千问是一句一次：用这一句开始时的音色和语速去合成，音频一块块回来，第一块到了就出声，不等整句合成完。

从这一句交出去，到说完、被停掉、或这一次失败回来，都算「正在播」。还在连接、喇叭还没出声的这段也算。听法在这段里不改口，规则见 07 第 10 节。

停止、插话命中、退下，立刻停掉已经出的声音，并取消还没合成完的那一句。千问这一次的连接一起关掉，还没回来的音频不再播。队列按 07 和 05 清空。

本地的合成和播放仍按现在的行为。本地那一句在合成过程中停不掉、只能丢掉结果，这一点不在本文改。

声音仍从现在的播报出口出去。出口前按设置乘上音量增益，本地和千问走同一条。听法不用知道这一句是本地合成的还是千问合成的。

## 6. 本次不做

- 设置里的试听按钮。
- 播报失败时的弹窗，或在设置里标出某一次失败。
- 音高，或让用户改千问的语言。
- 方言单独一项。方言只在音色列表里。
- 选了千问之后，因为 Key 空、Key 无效或请求失败而改走本地。
- 从环境变量或本机 shell 配置读取 API Key。
- 地域切换，或让用户填写模型名。
- 本地和千问以外的第三种播报。
- 千问沿用本地的中英文拆开和分速。本地自己的语速范围和合成方式保持不变。
- 把途中没赶上喇叭的正文补播。仍按 05。

## 7. 实现时对照的材料

交互以本文为准。千问的连接方式、音色原文和语速上下限见：

- `~/Projects/tts_native/docs/Qwen3-TTS-Flash-Realtime-落地实现文档.md`

本地模型的下载、文件和合成参数仍见 05 文末列出的 Matcha 文档。

从千问那份材料带进产品的约束：

- 模型名是 `qwen3-tts-flash-realtime`。音色用本文第 4 节的 voice 列，不用另一套模型的音色名。
- 语速只到 2.0。超过的按 2.0 念。
- 音频按块回来就播。等整句到齐再播，第一声会晚很多。
- 用户停掉时，这一次云端请求要真正取消。
