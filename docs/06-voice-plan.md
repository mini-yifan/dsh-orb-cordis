## 0. 结论

能做。要新写的是同一路麦克风上的切换、听与不听的状态、播报队列、设置项和模型下载。唤醒、听写、朗读的引擎沿用上面三份文档里已经跑通的 sherpa-onnx 方案。

现有悬浮球已经具备这些接缝：

- 单击固定、悬停展开、拖动取消固定并收回，都在 `packages/helper/assets/shell.js`
- Agent 一开始干活会展开并固定（`showWorkPanel`）
- 停止按钮已经能取消这场执行；Host 在没有执行时收到停止是空操作（`stopTurn`）
- 提问卡、点选、取消已经走控制 socket
- 打字发送走 `api.send` → `orb:prompt`，识别结果走同一条
- 显示框只收到当前这场的块。Host 不把别的会话推到球上
- 设置页是主窗口里的 client 插件，读写 Host 的 HTTP

官方 dsh 不改。Linux 上没有悬浮球，语音这一组也不出现。

## 1. 放在哪个进程

引擎放在 **helper 主进程**。页面只保留固定、鼠标、空闲计时和「这段文字算途中还是收尾」的判断。

| 候选 | 决定 |
|---|---|
| helper 主进程 | 采用。麦克风、播放和固定状态在同一个进程里。唤醒和听写切换时不断开设备 |
| Host | 不用。Host 是官方进程里的 Node 模式。原生崩溃或大约 1.5GB 的常驻内存会带走 Computer Use。固定和鼠标本来就在 helper |
| 再开一个语音进程 | 第一版不拆。采集回调里本来就不能跑识别，识别放 worker 线程即可。helper 若被原生模块打崩，再拆 |

页面到主进程只传模式和要念的句子。音频样本不出渲染进程。

## 2. 听法

听法由页面上已经有的状态算出来，外加「喇叭是否还在出声」。纯函数放在 `packages/helper/assets/voice-policy.js`，`shell.js` 调用它，测试方式和 `transcript-model.js` 相同。

```
listenMode({ pinned, running, asking, ttsBusy, wakeEnabled, inputEnabled })
  → 'wake' | 'command' | 'off'
```

| 条件 | 模式 |
|---|---|
| 没固定，Agent 空闲，喇叭空闲，唤醒开着 | `wake` |
| 已固定，Agent 空闲，喇叭空闲，语音输入开着 | `command` |
| Agent 正在执行，或提问卡在等，或喇叭在出声（含「我在」「好的，再见」、收尾、提问提示语） | `off` |
| 上面那一列对应的开关关着 | 该模式不出现，其余照旧 |

`running` 和 `asking()` 就是 `shell.js` 里现有的两个量。悬停展开不改 `pinned`，所以悬停时仍然只听唤醒。

干活途中单击球会取消固定，面板先留着。此时 `running` 仍为真，模式保持 `off`。执行和播报都结束后，再按当时的 `pinned` 进入 `wake` 或 `command`。

`ttsBusy` 在任意一句还在播、或队列里还有收尾 / 提问提示语时为真。这样「我在」播完之前，麦克风里的声音不会被当成指令。

主进程收到模式后只改路由，不重新打开设备：

- `wake`：样本送进 KeywordSpotter
- `command`：样本送进 Silero VAD，段闭合后把这一段交给 worker 里的 SenseVoice
- `off`：样本丢掉，并把 KWS / VAD 的流 reset。播报的回声不会在恢复收听时被解出来

从 `wake` 切到 `command` 的那一下不断流。固定之后用户立刻开口，句首留在语音输入这边。VAD 的段首回补仍用文档里的 0.3 秒。

播完后立刻恢复喂流。先不额外丢一段尾巴。真人验收时如果「我在」的余音被识别成指令，再加一段不超过 150 毫秒的丢弃，并复测「播完马上说」的句首。

## 3. 同一路麦克风

一条 node-cpal 采集，16kHz、单声道、float32。设备不是 16k 时用 sherpa 的线性重采样，和唤醒文档里的命令行版一样。

设备打开的条件：唤醒开关或语音输入开关至少有一个开着，并且对应模型已经就绪。两个都关掉、helper 退出、或用户拒绝麦克风权限时关闭。

识别离开采集回调。SenseVoice 一次解码要几十到一百多毫秒，放在采集线程里会让 CoreAudio 报 xrun。VAD 的 `numThreads` 用 1。KWS 用 2。ASR 用 2。这些不进设置。

语音输入的切段参数写死，与 VAD 文档、以及 DeepSeek Harness 内置的那一套对齐：

| 参数 | 值 |
|---|---|
| 语音阈值 | 0.5 |
| 静音判定 | 0.5 秒 |
| 最短人声 | 0.25 秒 |
| 单段最长 | 30 秒 |
| 窗长 | 512 |
| 段首回补 | 0.3 秒 |
| 语言 | auto |
| 逆文本归一 | 开 |

说的过程中页面不出现逐字稿。段闭合后主进程把整段文字交回页面。

## 4. 唤醒、退下、空闲

### 4.1 唤醒

KWS 命中后主进程发一条 `voice-wake`。页面做和单击钉住相同的两件事：`setExpanded(true)`、`pinBall()`。不发送，不把唤醒词写进对话。

然后再念回复语。出厂「我在」。回复语为空，或 TTS 关着，就只固定、不发声。这句只走喇叭。

已固定时模式是 `command`，KWS 不再吃样本，再喊没有反应。

命中后 reset 流，并套上设置里的冷却。出厂 1.5 秒。冷却之内的再次命中丢掉。

出厂唤醒词在第 0 步用真人麦克风定下来，候选是「你好小球」和「嘿小球」。定稿写进设置的默认值。词要四个音节左右、不要用单独的「你好」、也不要用英文品牌词。英文唤醒在那份文档里明显弱。

改词时用唤醒文档里的音素转换（`pinyin-pro`，和官方 `text2token` 逐字节对齐）。生成的 `keywords.txt` 只有 token 行。注释或空行会让解析器把进程打崩。灵敏度、增强分、判定粒度只能在创建引擎时生效，改动就重建引擎（大约 250 毫秒），麦克风保持开着。判定粒度 160ms 用 chunk-8 那套文件，320ms 用 chunk-16。两套都下载。

### 4.2 语音输入变成一条消息

整段文字回到页面后，先做退下匹配。没中，就走现在打字发送的同一条路：长度限制、屏幕录制和辅助功能检查、`composeSend`、`api.send`。用户气泡由 Host 回推，页面不自己画一条。

权限引导拦住时，这句话放进输入框，不发送。打字被拦住时草稿也是留在框里的。

固定还在，下一句直接说。不必再唤醒。

### 4.3 退下

匹配前先规范化：去掉首尾空白，去掉首尾的 `。！？!?.,，、；;：:`。SenseVoice 开了逆文本归一之后，口令常会多一个句号。规范化之后必须和某一条口令完全相等。夹在别的话里不相等，就不触发。

命中时：

- 不进输入框，不发送
- 取消固定。面板收不收沿用 `scheduleCollapse`：鼠标不在悬浮球窗口上就收回
- 念退下回复语。出厂「好的，再见」。回复语为空或 TTS 关着，就只取消固定

一条口令都没填，就没有退下。Agent 在干活、提问卡在等、或收尾还在播时，模式是 `off`，这段话说不到。

### 4.4 空闲计时

计时器在页面里，和 `pinned` 放在一起。进入「已固定、Agent 空闲、没有提问卡、收尾和提问提示语都已播完」时，从设置里的时长开始倒计时。出厂 30 秒。

到时只取消固定，然后按当时鼠标位置决定面板留不留。不念退下回复语，不发送。输入框里没发出去的字保留。

鼠标停在球上或显示框上不重置、也不暂停。

| 事件 | 计时器 |
|---|---|
| 输入框有按键，或发出一条文字指令 | 重新从满时长计 |
| 一段语音已经开口、还没闭合 | 停住 |
| 这段语音已经作为指令送出 | 重新从满时长计 |
| Agent 正在执行、提问卡在等、收尾或提问提示语还在播或还在队列里 | 停住；这些都结束后，把剩下的时间走完 |
| 取消固定 | 计时器取消。下次固定再从头计 |

「我在」和「好的，再见」不暂停这 30 秒。前者很短，后者说出口时固定已经取消。

拖动球时现有逻辑会取消固定并收回。计时器跟着取消，模式回到唤醒。

设置里的时长改动从下一次开始计时生效。滑条范围取 5 到 600 秒。需求没有写上下限，0 秒会一固定就取消，所以下限放到 5 秒。

## 5. 播报

合成和播放都在 helper 主进程，和 Host 的这一轮执行并行。Host 不等音频。

文本层从 Matcha 文档的参考实现搬过来：Markdown 清洗、符号规范化、中英分段、切句、双引擎拼接、SOLA 变速。模型 `speed` 封顶 1.5。设置里的目标倍速高于 1.5 时，用文档里的 `planSpeeds()` 把多出来的部分交给 SOLA。中英按同一个目标倍速，走文档里的「同速」那一列。出厂 1.5，滑条 1.0 到 3.0，步进 0.1。

播放用主进程里可立即停掉的 PCM 输出（22.05kHz）。停的时候丢掉当前缓冲。晚到的合成结果用一个代数丢掉，不等那次 `generate()` 结束，它只有几十毫秒。

### 5.1 哪段文字拿去念

只看当前显示框里、`kind === 'assistant'` 的块，也就是模型输出里的 `text`。思考、工具、状态句、提问卡上的题目和选项不进喇叭。

Host 已经只推当前这场。换场（`onSession` 的 id 变了、新建、打开历史里的另一场、`onReset`）时：停掉正在播的，清空队列，清掉下面的句读游标。

每个 assistant 块记一个已处理下标。块的全文每次是整段替换。新文本仍以前一次为前缀，就接着往后切；否则下标回到 0。

切句用文档里的 `takeReadyPrefix`：句号、问号、叹号处切开；满 60 字才在逗号处切；不切开小数、版本号和还没写完的英文单词。代码围栏没闭合时不送去合成。

| 时机 | 处理 |
|---|---|
| `running` 为真，切出一句完整的话 | 途中正文。喇叭空着就播；正在播就丢掉。丢掉的也把下标往后移，之后不补 |
| 这一轮 `turn` 变成结束 | 各 assistant 块里下标之后剩下的文字，按块顺序拼成一段收尾。没写完标点的尾巴也算进去 |
| 提问卡弹出 | 另发一句提问提示语，出厂「我有几个问题，你来选一下」 |

同一轮里的收尾是一段。连续几句拼在这一段里，占队列里的一个收尾名额。

### 5.2 队列

喇叭空着，新的正文、提问提示语、本地回复语都直接播。

喇叭正忙时：

| 新来的 | 动作 |
|---|---|
| 途中正文 | 丢掉 |
| 收尾 | 放进队列。队列里已有收尾就换成这一段。不碰提问提示语那个名额 |
| 提问提示语 | 放进队列，单独一个名额。已有一条在等就留原来的。一张卡一句 |
| 本地回复语 | 只在喇叭空闲时出现。唤醒和退下都发生在 Agent 空闲、播报已结束之后 |

收尾和提问提示语都在等时，按先到先播。谁也不挤掉谁。

提问卡被点选或取消：这句提示语正在播就立刻停；还在队列里就拿掉。Agent 另外用正文写过的问题，仍按正文走。

提示语为空或 TTS 关着：卡片照样出现，等待期间麦克风仍然关闭。

### 5.3 和执行的关系

途中那句赶得上就播，赶不上就让给提问或收尾。工具调用在 Host 里继续，不看喇叭。

收尾还在播，或提问卡还在等，听法保持 `off`。两件都结束后再按第 2 节恢复。

## 6. 停止按钮

现有条件是「展开了，并且 `running`」。加上一条：展开了，并且收尾正在播或还在队列里，按钮也留着。

提问卡在等的时候，这一轮在现有 Host 里仍然是 `running`，按钮本来就在。第 0 步用一次真实的提问卡确认这件事。若卡片还在而 `running` 已经落下，按钮改成这三者任一就留：正在执行、提问卡在等、收尾还在。

「我在」和「好的，再见」不让按钮多留。

两段都结束（执行结束，并且收尾播完或被停掉）按钮才消失。收尾还在播时面板保持展开。播完或被停止之后，若固定已经取消，再走现有的收回。

点击时：

- 页面照旧发 `orb:stop`。Host 没有正在执行的一轮时直接返回
- 主进程停掉当前 PCM，清空收尾和提问提示语，代数加一

然后按第 2 节恢复麦克风。

TTS 开关关掉之后，按钮只跟 Agent 执行，不为播报多留。

## 7. 设置

存在配置档的新文件 `orb-voice.json` 里，和 `ball-enabled.json` 那组并列。缺文件时用下表的出厂值，旧配置档不用迁移。

设置页在「设置 → 悬浮球」里加一组「语音」。球上「打开悬浮球设置」本来就进这一页。读写仍走现有的 `GET/POST /.dsh-orb/settings`。Host 在 `publishChrome` 时多广播一条 `voice`，helper 连上和每次保存都收得到。

| 项 | 出厂 | 页面控件 |
|---|---|---|
| 唤醒开关 | 开 | 开关 |
| 灵敏度 | 0.25 | 滑条 0.05–1.00，步进 0.05 |
| 增强分 | 1 | 滑条 0.5–5，步进 0.5 |
| 判定粒度 | 160ms | 160 / 320 |
| 连触发冷却 | 1.5 秒 | 滑条 0.5–5 秒 |
| 唤醒词 | 第 0 步定稿 | 多行，一行一个 |
| 唤醒回复语 | 我在 | 单行。空则不说 |
| 语音输入开关 | 开 | 开关 |
| 退下口令 | 你退下吧、退下吧 | 多行，一行一个。全空则没有口令 |
| 退下回复语 | 好的，再见 | 单行。空则不说 |
| TTS 开关 | 开 | 开关 |
| 提问提示语 | 我有几个问题，你来选一下 | 单行。空则不说 |
| 语速 | 1.5 | 滑条 1.0–3.0，步进 0.1 |
| 空闲时长 | 30 秒 | 滑条 5–600 秒 |

灵敏度、增强分、粒度和冷却的滑条两端需求没有写，上表是实现时的取值范围。语音输入不再提供 VAD / ASR 参数。

三项开关可以单独关。关掉的那一列不再发生，固定、收回、上屏、发送仍走现有逻辑。

Mac 的权限卡片加一行麦克风。弹窗上的名字是 helper 这份 Electron，系统设置里显示为 Electron。文案照实写，和现在屏幕录制那一行的写法一样。不去改已签名的 Electron 包名。Windows 在第一次采集时走系统的麦克风隐私开关，设置页写明要授权的是悬浮球运行时。

模型还在下载时，球可以打字。唤醒、听写、朗读等各自的文件就绪后再开。设置页用和 Electron 运行时同一套进度行。

## 8. 模型从哪来

模型不打进 npm 包。KWS 大约 15MB，TTS 大约 214MB，ASR 大约 241MB。包里只放引擎的原生模块。

Host 按 `electron-runtime.ts` 的方式下载到 `dshHomePath('dsh-orb', 'voice-models')`：先对清单做 sha256，再换入目录。三个开关全关时不下载；下载进行中用户把三个都关掉，就中止。出厂三个都开，所以第一次启动会在后台下。helper 先起来，不挡在下载后面。

| 引擎 | 文件 | 获取 |
|---|---|---|
| KWS | chunk-8 与 chunk-16 的 int8 encoder / joiner、fp32 decoder、`tokens.txt`、`en.phone` | 按唤醒文档的发布包下载。fp32 encoder 和测试音频不带 |
| ASR | SenseVoice `model.int8.onnx`、`tokens.txt`、`silero_vad.onnx` | 优先用 `~/.dsh/speech-to-text/sensevoice/models` 里哈希对得上的那份。没有再下到 `voice-models`，哈希与 VAD 文档里 DSH 锁定的一致 |
| TTS | 中文 Matcha、英文 Matcha、`espeak-ng-data`、`vocos-22khz-univ.onnx`、三份 fst | 按 TTS 文档的 sha256。jieba 的 `dict/` 不带。vocoder 只存一份，两套模型用软链 |

加载时机：唤醒模型在唤醒开着且文件就绪时加载；ASR 在语音输入开着且第一次进入 `command` 时加载；TTS 在第一次要出声时加载。关开关不卸载，避免来回重建。helper 退出时一起退出。

常驻大约是：KWS 100MB，ASR 0.9GB，中英 TTS 0.5GB。三个都用上时 helper 多出大约 1.5GB。8GB 内存的机器会紧，这一点写进设置页那组的说明里。

原生模块和 koffi 一样打进 `dsh-orb` 的 `node_modules`，平台是 darwin-arm64、darwin-x64、win32-x64。`pack.mjs` 去掉它们的 install script，避免 pnpm 的构建脚本门禁。helper 的 tsdown 把 `sherpa-onnx-node` 和 `node-cpal` 留在包外，用 `createRequire` 加载。版本锁 `sherpa-onnx-node@1.13.8`。

| `packages/helper/assets/shell.js` | 调 policy，接唤醒、发送、退下、空闲、停止按钮、收尾切句 |
| `packages/host/src/voice-assets.ts` | 下载、校验、ASR 复用 `~/.dsh` |
| `packages/host/src/preferences.ts` | `orb-voice.json` |
| `packages/host/src/routes.ts` | snapshot 增加 `voice`，POST 写回 |
| `packages/host/src/orb.ts` | `publishChrome` 时广播 `voice` |
| `packages/client-settings/client.js` 与 `packages/bundle/client.js` | 「语音」这一组。两处文案保持同一次改动 |
| `packages/bundle/scripts/pack.mjs` | 把两只原生模块按 koffi 的方式放进 tarball |

页面到主进程的消息：

| 方向 | 名字 | 内容 |
|---|---|---|
| 页面 → 主进程 | `voice-mode` | `wake` / `command` / `off` |
| 页面 → 主进程 | `voice-speak` | `{ role: 'interim' \| 'final' \| 'prompt' \| 'local', text }` |
| 页面 → 主进程 | `voice-stop` | 停播并清空队列 |
| 主进程 → 页面 | `voice-wake` | 命中了唤醒词 |
| 主进程 → 页面 | `voice-transcript` | 一整段识别文字 |
| 主进程 → 页面 | `voice-state` | `{ speaking, agentQueued }`，用来算 `ttsBusy` 和停止按钮 |

退下口令和回复语留在页面。主进程只对唤醒词和引擎参数负责，因为那两项要重建 KWS。

## 10. 步骤

每一步结束，球都还能打字、还能操作屏幕。语音没就绪时当作那一项关着。

### 第 0 步：在 helper 的 Electron 里跑通三件事

用仓库锁定的 Electron 44 加载 `sherpa-onnx-node` 和 `node-cpal`，打开默认麦克风，对候选唤醒词喊一次，说完一句能出整段文字，念一句能出声并且能马上停。

这一步同时定出厂唤醒词，并看一次真实提问卡到来时 `running` 是否仍为真。

过不了就停。预编译包是 N-API，按预期能直接加载。若 Electron 44 拒载，再针对这份 Electron 的头文件重编，把编出来的二进制放进 tarball。不为此改交互。

### 第 1 步：状态和队列，先不接麦克风

`voice-policy.js` 用单测覆盖第 2、4、5、6 节的表：听法、退下的整句相等、空闲计时的停与重置、途中丢掉、收尾只留一段、提问提示语不被收尾挤掉、换场清空、`1.13.8` 不被切碎。

设置的读写、缺文件时的出厂值、非法值夹回上表范围，放在 Host 现有的 preferences 测试里。

### 第 2 步：接上球

唤醒钉住面板并说「我在」，然后听指令。指令上屏并发送。退下不上屏。30 秒只取消固定。停止同时停执行和播报。提问卡只念那一句提示语，点选或取消时这句停下。

模型下载放在这一步后面半段。下载未完成时球保持可打字。

### 第 3 步：设置页和安装包

主窗口那一组控件能改第 7 节的每一项，改完球立刻按新值工作。唤醒参数改动后麦克风不断开。`pack.mjs` 的安装测试像 koffi 那样断言原生模块在 tarball 里，并且没有 install script。

## 11. 验收

对照 [05-voice.md](05-voice.md) 第 8 节走一轮，外加下面这些：

- 没固定时喊唤醒词，面板钉住并说「我在」。这句话不在对话里。播完再说指令，句首还在
- 已固定时再喊唤醒词，没有第二次「我在」，那句话也不会被当成指令
- 「查一下今天的天气」整句上屏并发送。思考和工具卡没有声音。执行期间喊话没有反应
- 途中一句在喇叭空着时能听到。用长收尾占住喇叭时，下一句途中的话不补播
- 提问卡只听到「我有几个问题，你来选一下」。点选后这句停止，麦克风要等到这轮和播报都结束才再开
- 收尾赶上就立刻播，赶不上就排在当前这句后面。停止按钮在收尾期间还在。点停止后声音停、队列空、按钮消失
- 「退下吧。」（带句号）不上屏、不发给 Agent，只取消固定，并说「好的，再见」。鼠标在面板上时面板留着
- 30 秒内不打字、不说话，只取消固定。鼠标一直停在球上也会取消。输入框里没送出的字还在
- 三个开关分别关掉，对应的那一列停止，另外两列还在
- 换一场对话，上一场的声音立刻停
- 主窗口里另一场会话写出正文，球上没有声音

单测覆盖第 1 步。真人麦克风覆盖上面这一列。CI 不打开麦克风。

## 12. 风险

| 风险 | 处理 |
|---|---|
| Electron 44 加载不了预编译的 `.node` | 第 0 步当天验证。失败则按 Electron 44 重编后再装 |
| 麦克风权限弹窗写着 Electron | 接受。设置页写明要勾的是悬浮球运行时，名字是 Electron |
| 外放回声把播报听成指令 | 出声期间听法是 `off`，恢复时 reset 流。余音若仍被收下，再加第 2 节那 150 毫秒 |
| helper 多 1.5GB | 按用到的引擎懒加载。设置说明里写上内存 |
| 中文 Matcha 权重仅限非商用；KWS 权重许可未定；SenseVoice 走 FunASR 模型许可 | 做功能不挡。对外发布前单独确认这三项。换引擎会改第 8 节的文件清单，不改交互 |
| `keywords.txt` 写进注释导致进程 abort | 生成器只写 token 行，单测锁住这一点 |
| 第一次启动要下大约 230MB（本机已有 DSH 语音模型）到 470MB | 后台下，不挡打字。失败时设置页给出重试，球保持可用 |
