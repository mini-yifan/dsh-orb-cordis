> 状态：Draft v0.1（计划对齐）
> 日期：2026-11-10
> 范围：单租户自建互联 v0（Mac + Windows 验收）；Android 悬浮球并行
> 关联：[14-interconnect-prd.md](14-interconnect-prd.md)、[15-existing-assets.md](15-existing-assets.md)

## 0. 计划摘要

### 0.1 这一版要做什么

- **不做账号体系**：没有注册/登录/多用户；一个自建服务 = 一个信任域。
- **自建服务部署在阿里云 Linux 公网服务器**：管理员页面 + 设备配对 + 在线状态 + 中继。
- **管理员手动加设备**：每台设备一个一次性配对码；设备输入码后接入。
- **Mac + Windows 验收**：两台电脑互相看到对方的工作区/会话，能实时看、输入、暂停；悬浮球能跨设备派后台 Agent；文件双向。
- **自定义 Mesh UI**：在悬浮球插件里做多设备树/会话界面；**官方 DSH 左栏尽量不改**。
- **Android 悬浮球并行**：基于 dsh-Go 做手机版悬浮球；v0 不接互联，独立验收。
- **v0 先不做**：账号/注册/登录、内置服务、多用户、手机作为互联节点、官方 DSH 左栏统一树、完整审批路由/审计、N 设备并发。

### 0.2 v0 完成定义

**Mac + Windows 能完整演示以下 9 条，且没有登录页：**

1. 阿里云服务器部署完成，管理员页面可添加设备、生成配对码；
2. Mac/Windows 用配对码接入，网站能看到设备名、平台、在线、上次在线；
3. 两台电脑的 Mesh UI 都能看到「本机 + 对方设备 → 工作区 → 会话」；
4. 打开对方会话，实时看消息/工具/状态；
5. 能给对方会话发新指令、暂停；
6. Mac 悬浮球能派后台 Agent 到 Windows 执行，Mac 实时看到，结果回到 Mac；
7. 文件双向：Mac 发给 Windows，Windows 回传；
8. 改名/离线/撤销：当前设备改名、对方/网站只读；离线/失败有明确状态；撤销后不能连；
9. 全程 E2E（服务器不解密），无账号/登录。

**Android 悬浮球 v0 独立演示：**

1. 手机上出现全局悬浮球；
2. 长按说话、松手发送；
3. 发送时附带当前屏截图；
4. Agent 能对当前屏做 Computer Use，敏感操作确认；
5. 有 Orb 面板/停止/本机后台 Agent；
6. 继承 dsh-Go 支持的 Android 机型/系统范围。

## 2. v0 产品范围

### 2.1 做

**服务端（阿里云 Linux）**

- 管理页：管理员口令登录；添加/删除设备、生成/作废配对码、改名、撤销、查看在线/审计；
- 设备注册/配对：一次性配对码、设备公钥、设备 token；
- 在线状态/心跳；
- 中继/信令：设备之间会话流、控制消息、文件传输；
- E2E：服务器只转发密文；
- 限流、日志、备份、监控、TLS。

**Mac / Windows 设备端**

- 悬浮球插件里的「互联」模块：填服务器地址、输入配对码、显示当前设备名/在线；
- 设备身份/密钥、连接、重连；
- 暴露本机 DSH 工作区/会话给 Mesh；
- 连接对端设备、拉取工作区/会话、订阅实时流；
- 远程会话：看、输入、暂停；
- 跨设备后台 Agent：`device_agent` 任务；
- 文件双向；
- 任务状态/通知/错误。

**Mesh UI（自定义）**

- 从悬浮球菜单/设置打开独立的 Mesh 窗口/面板；
- 左侧：设备 → 工作区 → 会话树；
- 右侧：会话 transcript、工具状态、输入框、暂停/停止；
- 顶部：在线状态、当前设备、刷新/重连；
- 任务卡、附件、文件去向；
- **不修改官方 DSH 左侧工作区**。

**Android 悬浮球（并行）**

- 全局悬浮球；
- 长按录音/松手发送；
- 发送时截图；
- 手机 Computer Use；
- Orb 面板/停止/本机后台 Agent；
- 暂不接互联。

### 2.2 不做（v0）

- 账号/注册/登录、OAuth、多用户、团队；
- 内置服务（只做自己的自建服务）；
- 手机作为互联节点/被调用端；
- 官方 DSH 左栏统一树、主聊天区多 Host；
- 完整审批路由、审计报表、计费；
- N 设备并发/多 Host 同时在线（v0 只验收 2 台）；
- P2P/TURN（先 Relay；后续）；
- 远程桌面、全量文件同步、离线任务队列；
- 跨账号联邦。

### 2.3 与 PRD 的差异

| PRD | v0 做法 |
|---|---|
| 账号/登录/内置服务 | 不做；单租户自建 |
| 设备命名 | 当前设备改名；管理员后台可改；普通网站只读 |
| 统一树 | 自定义 Mesh UI；DSH 左栏不变 |
| 手机照片/手机作为节点 | 后续；Android 悬浮球先独立 |
| 审批/审计 | 基础审批/状态；完整审计后续 |
| 多设备 | 2 台（Mac + Windows）验收 |

## 3. 逻辑架构（计划级）

```
                阿里云 Linux（公网，HTTPS/WSS）
        ┌──────────────────────────────────────────┐
        │ 管理页 / 状态页                             │
        │ 设备注册 + 配对码 + 在线状态 + 审计          │
        │ E2E 中继 / 信令 / 文件通道                   │
        └───────────────▲───────────────▲──────────┘
                        │ 出站 WSS（E2E） │ 出站 WSS（E2E）
              ┌─────────┴──────┐   ┌────┴──────────┐
              │ Mac             │   │ Windows        │
              │ DSH + 悬浮球     │   │ DSH + 悬浮球    │
              │ 互联模块         │   │ 互联模块        │
              │ Mesh UI         │   │ Mesh UI         │
              │ 本机 DSH         │   │ 本机 DSH        │
              └─────────────────┘   └────────────────┘

Android（并行，v0 不接互联）
  手机 dsh-Go + 悬浮球：长按语音 + 截图 + 手机 CU + 面板
```

要点：

- 设备只**出站**连接服务器，不开公网入站端口；
- 服务器只做管理/配对/在线/中继，**不解密会话/文件**；
- Mesh UI 在悬浮球插件侧，不改 DSH 左栏；
- Android 悬浮球是独立工作流，不依赖账号/互联。

> 以上是逻辑图，不是接口设计；具体协议/存储/部署在技术设计稿中定。

## 4. 关键流程

### 4.1 管理员添加设备

1. 管理员打开 `/admin`，用管理员口令登录；
2. 新增设备（名称/平台/备注）；
3. 生成一次性配对码（有效期/次数限制）；
4. 在 Mac/Windows 悬浮球「互联」里填服务器地址 + 配对码；
5. 设备生成密钥、提交配对码/公钥；服务器校验、绑定设备、发设备 token；
6. 设备上线，管理页/状态页显示在线；
7. 管理员可撤销/改名/重新生成配对码。

### 4.2 设备上线/在线状态

- 设备启动后连服务器；心跳；
- 状态页显示：名称、平台、在线、上次在线；
- 管理页显示：设备、配对码、会话/任务（基础）、审计；
- 离线/重连有状态。

### 4.3 Mesh UI

1. 从悬浮球菜单/设置打开 Mesh；
2. 显示「本机 + 其他设备」→ 工作区 → 会话；
3. 点远程会话：拉取历史 + 订阅实时；
4. 输入/暂停/停止；
5. 任务卡/附件/状态；
6. 离线设备显示缓存和“离线”。

### 4.4 跨设备后台 Agent

1. Mac 悬浮球收到任务；
2. 判断目标设备（用户指定/按名称/平台）；
3. 调用 `device_agent`：目标设备、任务、附件；
4. 目标设备创建标准后台会话；
5. Mac Mesh UI 出现该会话，实时显示；
6. 用户可暂停/插话；
7. 完成后结果/文件回到 Mac，悬浮球汇总。

### 4.5 文件双向

- Mac 本地文件 → 目标会话附件 → 目标 Agent 拿到路径；
- 目标 Agent 结果文件 → 回传 Mac → Mesh 会话附件；
- 大文件进度/失败/清理；
- 手机照片 v0 不接（Android 悬浮球独立）。

### 4.6 Android 悬浮球

1. 全局悬浮球；
2. 长按录音，显示波形；
3. 松手：转写 + 截当前屏（隐藏球）；
4. Orb 面板显示消息 + 截图；
5. Agent 用手机操控对当前屏操作；
6. 敏感操作确认；可停止；
7. 本机后台 Agent/历史/新建。

### 4.7 撤销/离线/失败

- 管理员撤销设备 → token 失效、连接断开、树里消失；
- 设备离线 → 状态页/树显示离线；任务不派发或明确失败；
- 远程任务失败 → 可读原因 + 重试；
- 不静默失败、不假装完成。

## 5. 工作分解（Workstreams）

### WS1 服务端 / 管理页 / 配对 / 安全

**交付：**

- 阿里云 Linux 部署（Docker/系统服务均可）；
- 域名/TLS/反代；只开 443；安全组/防火墙；
- 管理页：管理员口令、设备 CRUD、配对码、改名、撤销、审计；
- 状态页：只读设备列表；
- 设备注册/配对/token/心跳；
- E2E 中继/信令/文件通道；
- 限流、日志、备份、监控、告警；
- 公网安全基线：管理员口令强度、配对码 TTL/一次性、失败限流、默认拒绝。

**退出标准：** 管理员能添加两台设备并看到在线；设备能配对/重连；服务器抓包看不到会话明文。

### WS2 Mac / Windows 设备端

**交付：**

- 悬浮球插件「互联」设置：服务器地址、配对码、设备名、在线、设备列表；
- 设备身份/密钥/ token/重连；
- 本机 DSH 工作区/会话暴露；
- 对端连接、工作区/会话拉取、实时订阅；
- 远程会话输入/暂停；
- `device_agent` 任务；
- 文件上传/下载；
- 状态/通知/错误。

**退出标准：** 两台电脑能互相看到工作区/会话；能打开、输入、暂停；任务/文件跑通。

### WS3 Mesh UI（自定义）

**交付：**

- 从悬浮球菜单/设置打开的 Mesh 窗口/面板；参考已有插件（如 ds-bot）的自建 UI 先例，按插件自建 UI 路线做，不改 DSH 左栏；
- 设备 → 工作区 → 会话树；
- transcript/工具状态/输入/暂停/停止；
- 任务卡/附件/文件去向；
- 在线/离线/重连；
- 中英文、深浅色、键盘操作；
- **官方 DSH 左栏不变**。

**退出标准：** 不打开官方 DSH 工作区，也能在 Mesh UI 完成 Mac/Windows 的看/输入/暂停/任务。

### WS4 跨设备 Agent / 文件

**交付：**

- `device_agent`：目标设备、任务、附件、等待、结果、取消；
- 目标标准后台会话；
- 完成通知/结果汇总；
- 文件双向、进度、大小限制、清理；
- 用户插话/暂停与 Orb 等待的协调。

**退出标准：** Mac 一句话，Windows 后台 Agent 完成文档任务并回传；文件双向成功。

### WS5 Android 悬浮球（并行）

**交付：**

- dsh-Go 分支/修改；
- 全局悬浮球；
- 长按语音/松手发送；
- 发送时截图；
- 手机 Computer Use；
- Orb 面板/停止/历史/新建；
- 本机后台 Agent；
- 敏感操作确认。

**退出标准：** 在 dsh-Go 支持的 Android 机型上，能完成“长按说话 → 截图 → 当前屏操作 → 结果”的闭环；不接互联。

### WS6 QA / 运维 / 验收

**交付：**

- Mac+Windows 9 条验收脚本；
- Android 6 条验收脚本；
- 安全测试：配对码复用/过期、未授权设备、撤销、管理员口令、E2E、限流；
- 性能测试：树加载、会话延迟、任务派发、文件传输、离线检测；
- 部署/备份/恢复/升级/监控文档；
- 问题清单与阻塞项。

### 7.3 安全/运维验收

- 配对码一次性、短 TTL、限流；失败不泄露设备信息；
- 管理员口令强密码；管理页 HTTPS；建议 IP 允许列表/2FA（后续）；
- 设备 token 可撤销；撤销后连接断开；
- E2E：服务器/中继无法解密会话/文件；
- 日志不含会话内容/密钥；
- 备份/恢复演练；
- 服务器只开必要端口；SSH key；最小权限；
- 阿里云安全组/防火墙/WAF（可选）。

### 7.4 性能目标（v0）

| 项 | 目标 |
|---|---|
| 树首次加载（2 台设备） | ≤ 2 秒（良好网络） |
| 远程会话消息延迟 | ≤ 1 秒（同区域） |
| 任务派发到开始执行 | ≤ 5 秒（在线设备） |
| 文件传输 | 有进度；失败可重试；不阻塞 UI |
| 离线检测 | ≤ 30 秒 |
| 设备重连 | 自动；状态可见 |

## 8. 公网服务器安全 / 运维

### 8.1 阿里云部署

- Linux; Docker/系统服务；
- 域名 + TLS（阿里云证书/Let's Encrypt）；Nginx/Caddy 反代；
- 只开放 80/443（80 跳转）；SSH 限制来源/IP；
- 安全组最小开放；fail2ban/限流；
- **中国大陆地域注意 ICP 备案/域名合规**；如不想备案，可选香港/海外地域（延迟/合规自行评估）。

### 8.2 管理员页面

- 独立 `/admin`；强管理员口令（≥ 16 位随机）；
- 建议 IP 允许列表；后续 2FA；
- 不与设备 API 混用 token；
- 管理员操作审计；
- 默认拒绝、失败限流；
- 不在页面显示会话内容/密钥。

### 8.3 设备配对

- 管理员生成一次性配对码（短 TTL、限次）；
- 设备提交码 + 公钥；服务器绑定；
- 码只存哈希；失败限流；
- 设备 token 可撤销；
- 设备名称默认 + 当前设备改名 + 管理员后台改名（特权）。

### 8.4 E2E

- 公网 v0 **必须 E2E**；TLS 不是 E2E；
- 复用成熟 Noise/等价方案优先；不自创加密；
- 服务器只转发密文；
- 设备公钥固定/校验；
- 密钥只在设备本地。

### 8.5 运维

- 日志（不含内容）、指标、告警；
- 备份/恢复（设备元数据/审计；不含会话）；
- 升级/回滚；
- 证书续期；
- 事故响应/撤销流程；
- 成本/带宽监控（中继）。
